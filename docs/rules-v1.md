# 四人リーチ麻雀 点数計算仕様 v1

## 目的

この仕様は、通常の四人リーチ麻雀における一人の和了について、和了形、役、符、基本点、支払いを決定するための初期仕様である。

ライブラリは対局進行を管理しない。牌姿だけから決まらない情報は、呼び出し側が `WinContext` として渡す。

## 対象範囲

- 四人麻雀
- ロンおよびツモ
- 親および子
- 門前および副露
- 通常形（4面子1雀頭）、七対子、国士無双
- 通常役、役満、ドラ、裏ドラ、赤ドラ
- 符計算
- 満貫、跳満、倍満、三倍満、数え役満
- 本場と供託リーチ棒

## 対象外

- 三人麻雀
- 青天井
- ローカル役
- 流し満貫などの流局時精算
- 複数ロンの優先順位と供託分配
- 責任払い
- 途中流局、連荘、順位点、ウマ、オカ
- 対局履歴からの一発、海底、天和などの推論
- 不正行為やチョンボの裁定

## 牌の表現

牌種は萬子、筒子、索子の1から9と、東南西北白發中の34種類とする。同一牌種は通常4枚までとする。

赤牌は牌種とは分けて属性として保持する。赤牌として有効なのは数牌の5だけである。赤牌の採用枚数は入力された実牌から数え、通常の牌種枚数制限にも含める。

手牌入力の `concealed_tiles` は和了牌を含めない。和了牌は `winning_tile` に一枚だけ指定する。副露牌は `melds` に指定する。

通常形の構造枚数は、暗槓・明槓を3枚相当として数えたときに14枚でなければならない。物理的な牌の総数は槓一つにつき一枚増える。

## 和了形

以下のすべての解釈を列挙する。

1. 4面子1雀頭
2. 異なる7種の対子からなる七対子
3. 国士無双

同じ牌姿に複数の4面子1雀頭分解がある場合、すべての分解について役と符を評価する。最終的な受取点が最大の候補を採用する。同点なら、翻数、符、正規化した和了形の順に比較し、結果を決定的にする。

## 状況入力

牌姿だけから決まらない以下の状態は `WinContext` で明示する。

- ロンまたはツモ
- 自風と場風
- リーチまたはダブルリーチ
- 一発
- 嶺上開花
- 槍槓
- 海底摸月
- 河底撈魚
- 天和または地和
- 本場
- 供託リーチ棒

矛盾する状態はエラーとする。例として、副露手のリーチ、ロンと門前清自摸和の同時成立、海底と河底の同時指定を認めない。

### 役満

- 天和
- 地和
- 国士無双
- 四暗刻
- 大三元
- 小四喜
- 大四喜
- 字一色
- 緑一色
- 清老頭

国士無双十三面待ち、四暗刻単騎、純正九蓮宝燈、大四喜はダブル役満とする。役満同士は複合する。役満成立時は通常役とドラを加算しない。

役による役満の `ScoreResult` は `han` と `fu` を0、ドラ内訳をすべて0とし、`Limit::Yakuman` の引数で合計役満倍率を表す。

## ドラ

ドラ、裏ドラ、赤ドラは翻数へ加算するが、役ではない。ドラだけの手は役なしとしてエラーにする。

裏ドラはリーチまたはダブルリーチ時だけ数える。ドラ表示牌は通常の次牌規則に従い、数牌は9から1、風牌は北から東、三元牌は中から白へ循環する。

同じ表示牌が複数指定された場合はそれぞれ加算する。赤ドラは手牌、副露、槓および和了牌から数え、表示牌自体は赤ドラ枚数に含めない。

## 符

- 副底は20符
- 門前ロンは10符
- ツモは2符。ただし平和ツモは20符固定
- 七対子は25符固定
- 符のある通常形は合計を10符単位で切り上げる
- 副露した平和形のロンは30符とする
- 雀頭、待ち、刻子、槓子の符を通常の規則で加算する
- 連風牌の雀頭は既定で4符とし、`double_wind_pair_fu` には2または4を指定できる

刻子・槓子の符は次のとおりとする。

| 面子 | 中張牌 | 么九牌 |
|---|---:|---:|
| 明刻 | 2 | 4 |
| 暗刻 | 4 | 8 |
| 明槓 | 8 | 16 |
| 暗槓 | 16 | 32 |

ロン牌で完成した刻子は符および三暗刻・四暗刻の判定上は明刻として扱うが、手全体の門前状態は失わない。

## 基本点と上限

満貫未満の基本点は次式で求める。

```text
基本点 = 符 × 2^(翻数 + 2)
```

通常ルールでは以下を適用する。

| 条件 | 基本点 |
|---|---:|
| 5翻、4翻40符以上、3翻70符以上 | 2,000（満貫） |
| 6〜7翻 | 3,000（跳満） |
| 8〜10翻 | 4,000（倍満） |
| 11〜12翻 | 6,000（三倍満） |
| 13翻以上 | 8,000（数え役満、単倍） |

既定ルールでは4翻30符および3翻60符の切り上げ満貫を採用しない。`kiriage_mangan` を有効にした場合だけ満貫とする。

`counted_yakuman` を無効にした場合、13翻以上の通常手は三倍満で打ち止めとする。これは通常役満およびダブル役満の倍率には影響しない。

## 支払い

基本点から次の倍率を掛け、支払者ごとの金額を100点単位で切り上げる。

- 子のロン: 基本点の4倍
- 親のロン: 基本点の6倍
- 子のツモ: 親が基本点の2倍、他の子二人が基本点ずつ
- 親のツモ: 子三人が基本点の2倍ずつ

本場はロンなら放銃者の支払いへ一本300点、ツモなら各支払いへ一本100点を加える。供託リーチ棒は一本1,000点を和了者の受取点へ加えるが、和了点そのものや各支払額には含めない。

## エラー

少なくとも以下を区別する。

- 牌表現が不正
- 同一牌種が5枚以上
- 構造枚数が不正
- 副露の構造が不正
- 状況指定が矛盾
- 和了形でない
- 入力から得られない和了形を役判定に指定
- ルール設定が不正
- 成立役がない
- 点数計算の翻・符・本場・供託が不正

## 決定性と説明可能性

同じ入力とルールからは、バックエンドや実行順にかかわらず同じ結果を返す。結果には採用和了形、役と翻、ドラ内訳、符内訳、基本点、上限区分、支払いを含める。
